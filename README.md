# SIYADA — برنامج محاسبة للشركات التجارية

نظام محاسبي بقيد مزدوج مصمّم للشركات التجارية: مبيعات ومشتريات ومخازن وخزينة وعملاء وموردين وموظفين وتقارير مالية كاملة.
يعمل بطريقتين من **نفس الكود**:

| الوضع | الوصف |
|---|---|
| **ملف واحد (Offline)** | `SIYADA.html` يُفتح في أي متصفح بدون إنترنت وبدون تثبيت. البيانات تُحفظ في المتصفح (IndexedDB) مع نسخ احتياطي JSON. |
| **سيرفر (Multi-user)** | سيرفر Node.js بدون أي مكتبات خارجية وقاعدة SQLite: شركات متعددة، مستخدمون بصلاحيات، مزامنة شبه فورية، نسخ احتياطي يومي. |

> الإنجليزية: [README.en.md](README.en.md)

## الميزات

- **قيد مزدوج كامل** — محرك ترحيل واحد (`client/src/engine.js`) يحوّل الحركات إلى قيود متوازنة ويُراجع نفسه بفحوصات اتساق. لا توجد معادلات في أي مكان.
- **المبيعات والمشتريات** — فواتير ومرتجعات وسندات قبض وصرف، مع **العدد** و**وزن الصنف** (الكمية ÷ الوزن = العدد تلقائيًا).
- **مرجع المبيعات / المشتريات** — سطر واحد لكل فاتورة مع عدد البنود وتفاصيلها، وتعديل أو حذف الفاتورة من نفس الشاشة، و**الكمية بعد المرتجع** لكل عميل أو مورد أو صنف.
- **المخازن** — مخازن متعددة بأرصدة وتكلفة مستقلة، تحويل مباشر بينها، متوسط التكلفة المتحرك، حد الطلب، وقوائم أسعار.
- **الحسابات والتقارير** — دفتر الأستاذ، ميزان المراجعة، قائمة الدخل، المركز المالي، كشوف حساب العملاء والموردين، الخزينة والبنوك، إقفال السنة.
- **الضرائب** — تقرير ضريبة القيمة المضافة ومسودة فاتورة إلكترونية (JSON غير موقّعة).
- **الموظفون** — بيانات الموظفين، السلف وسدادها، مرتب الشهر بخصم السلف، قسيمة المرتب، كشف حساب الموظف.
- **واجهة بقائمة علوية** على نمط برامج المحاسبة المعروفة (عناوين وقوائم منسدلة وفرعية)، وتتحول إلى قائمة منزلقة على الجوال. واجهة عربية بالكامل من اليمين لليسار.
- **اسم الشركة** يُكتب مرة واحدة ويظهر في كل الشاشات والتقارير والطباعة.
- **استيراد** من ملفات CSV المصدّرة من نظام SIYADA على Excel، مع تطابق الأرقام للقرش (مُختبر آليًا).

## البدء السريع (للمطوّر)

المطلوب: **Node.js 22.13 أو أحدث**.

```bash
git clone <رابط-المستودع> siyada && cd siyada
npm run build          # ينتج dist/SIYADA.html (وينسخه إلى server/public)
```

- **الملف المستقل:** افتح `dist/SIYADA.html` في المتصفح.
- **السيرفر:** `npm start` ثم افتح <http://localhost:3000> — أول حساب يُسجَّل هو مدير الخدمة.
  على ويندوز يمكنك أيضًا الضغط مرتين على `server/start-windows.bat` (وعلى لينكس/ماك `server/start.sh`): يبنيان صفحة التطبيق تلقائيًا في أول مرة.
- **برنامج Windows:** بعد تثبيت متطلبات التطوير شغّل `npm run desktop:dist` لإنشاء `dist/desktop/SIYADA-Setup-1.0.0.exe`. النسخة المحلية لا تحتاج Node.js بعد تثبيتها، وبياناتها محفوظة على جهاز المستخدم.
  عند نشر إصدار جديد عبر GitHub Releases، يفحص البرنامج التحديث تلقائيًا ويطلب إعادة التشغيل لتثبيته.

للنشر على الإنترنت (Docker + HTTPS تلقائي) راجع [docs/DEPLOYMENT.ar.md](docs/DEPLOYMENT.ar.md).

## الاختبارات

```bash
npm test               # بناء + اختبار المحرك (تطابق الأرقام) + 108 اختبار للسيرفر
npm run test:e2e       # اختبارات المتصفح الحقيقي (Python + Playwright)
```

تثبيت متطلبات اختبارات المتصفح لمرة واحدة:

```bash
pip install -r tests/e2e/requirements.txt && python3 -m playwright install --with-deps chromium
```

التفاصيل في [docs/TESTING.md](docs/TESTING.md).

## هيكل المستودع

```text
siyada/
├── client/src/          كود التطبيق (وحدات JS + CSS + قالب HTML) — يُجمّع في ملف واحد
├── server/              سيرفر Node.js (lib/ + اختبارات + Dockerfile + Caddy + systemd)
├── scripts/
│   ├── build.js         يجمّع client/src في dist/SIYADA.html
│   ├── pack.py          يصنع حزمة التسليم SIYADA_Server.zip

├── tests/
│   ├── engine/          اختبار تطابق المحرك مع أرقام Excel
│   ├── e2e/             اختبارات المتصفح (Playwright)
│   └── fixtures/        بيانات تجريبية بأسماء وهمية
├── docs/                المعمارية والاختبارات والنشر
├── .github/             CI + الإصدارات + قوالب Issues / PR
├── CHANGELOG.md · CONTRIBUTING.md · SECURITY.md · LICENSE
└── package.json         أوامر المشروع (build / test / pack)
```

المعمارية بالتفصيل: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## الأمان والخصوصية

- لا تُرفع على GitHub أي بيانات حقيقية (ملفات Excel، قواعد البيانات، تصديرات العملاء). `.gitignore` يمنع ذلك، والبيانات التجريبية الموجودة مُخفاة الهوية.
- ملف `.env` وكلمات المرور والـ SMTP لا تُرفع أبدًا. القالب الوحيد المسموح هو `server/.env.example`.
- الإبلاغ عن ثغرة: [SECURITY.md](SECURITY.md).

## حدود معروفة

سيرفر واحد وقاعدة SQLite واحدة (مناسب لعشرات الشركات لا آلاف)، والتطبيق يحمّل دفاتر الشركة كاملة في المتصفح، والفاتورة الإلكترونية مسودة غير موقّعة. القائمة الكاملة في [docs/DEPLOYMENT.ar.md](docs/DEPLOYMENT.ar.md).
