# SIYADA على ويندوز — التثبيت والاستخدام

## ١) إزاي تجيب ملف التثبيت (exe)

**الطريقة الأسهل: GitHub يبنيه لك.**

1. من مجلد المشروع على جهازك (`D:\New folder\github` مثلًا) افتح cmd واكتب:
   ```
   git add -A
   git commit -m "SIYADA 1.1.0"
   git push
   git tag v1.1.0
   git push origin v1.1.0
   ```
2. افتح صفحة المستودع على GitHub ← **Actions** وانتظر لحد ما يخلص الـ workflow اسمه **Release** (حوالي ١٠ دقايق).
3. ادخل **Releases** ← هتلاقي `SIYADA-Setup-1.1.0.exe` و `SIYADA.html` و `SIYADA_Server.zip`.
4. نزّل الـ exe وشغّله واتبع الخطوات (بيسألك على مكان التثبيت، وبيعمل أيقونة على سطح المكتب).

لو عايز تبنيه على جهازك بدل GitHub: `npm ci` ثم `npm run desktop:dist` (محتاج Node.js)، والناتج في `dist\desktop`.

> ويندوز ممكن يظهر تحذير «SmartScreen» لأن المثبّت مش موقّع رقميًا. اضغط **More info ← Run anyway**.

## ٢) طريقتين للتشغيل

| الوضع | إمتى تستخدمه | الدخول والخروج |
|---|---|---|
| **على الجهاز بدون سيرفر** (الافتراضي) | جهاز واحد، البيانات محفوظة عليه | مفيش حسابات. تقدر تفعّل كلمة مرور قفل من الإعدادات. |
| **متصل بسيرفر الشركة** | أكتر من جهاز أو أكتر من مستخدم (مالك / محاسب / عرض فقط) | دخول بالإيميل وكلمة المرور، وتسجيل الخروج من قائمة الحساب أعلى اليسار. المزامنة بين الأجهزة تلقائية. |

### الاتصال بالسيرفر
1. شغّل السيرفر (الدليل في `docs/DEPLOYMENT.ar.md`) ولازم يكون ليه عنوان تقدر توصله من الجهاز، مثلًا `https://erp.شركتك.com` أو `http://192.168.1.10:3000` داخل الشبكة.
2. افتح SIYADA المثبّت. من القائمة أعلى النافذة اختار **SIYADA ← اتصال بسيرفر الشركة (حساب بالإيميل)**.
3. اكتب العنوان واضغط **اتصال**. البرنامج بيتأكد إن العنوان فعلًا سيرفر SIYADA.
4. أنشئ الحساب والشركة لأول مرة، أو ادخل بالإيميل لو اتدعيت. للخروج: قائمة الحساب ← **تسجيل الخروج**.
5. للرجوع للعمل على الجهاز: **SIYADA ← العمل على هذا الجهاز بدون سيرفر**.

لو السيرفر مش متاح عند فتح البرنامج، هتظهر رسالة بتديك: إعادة المحاولة، أو تغيير العنوان، أو العمل على الجهاز.

## ٣) الأدوات الجديدة

- **كليك يمين** على أي مستند في **مرجع المبيعات** أو **مرجع المشتريات**: عرض، تعديل، طباعة A4 / A5، كشف حساب العميل أو المورد، رسالة واتساب، نسخ الرقم، حذف.
- **رسائل واتساب**: بعد حفظ فاتورة بيع أو مرتجع أو تحصيل بتظهر نافذة برسالة جاهزة. رقم العميل بيتاخد من بطاقته، ولو مش موجود بتكتبه مرة واحدة وبيتحفظ. زر **فتح واتساب** يفتح المحادثة في المتصفح أو تطبيق واتساب. قوالب الرسائل من **رسائل واتساب ← إعدادات وقوالب الرسائل**.
- **خصم الكمية الشهري**: اتفاق لكل عميل (سعر الطن + حد أدنى)، بيتحسب على صافي الكمية بعد المرتجع، وبيترحّل بضغطة واحدة.
- المظهر **كحلي وذهبي** من الإعدادات (افتراضي للشركات الجديدة).

## ٤) النسخ الاحتياطي
البيانات في وضع الجهاز محفوظة داخل البرنامج. خُد نسخة JSON بانتظام من **ملف ← البيانات ← نسخة احتياطية**، وفي وضع السيرفر خُد نسخة من مجلد بيانات السيرفر.
